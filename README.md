# ZIFIX homepage clone

Static, dependency-free recreation of the https://zifix.sk/ homepage in plain HTML and CSS (no JavaScript).

- `index.html` – the page
- `assets/css/style.css` – all styling, including responsive breakpoints at 550px and 850px (matching the original Flatsome theme)
- `assets/img/` – images downloaded from the original site

Open `index.html` directly in a browser. The hero slider uses CSS scroll-snap with anchor links, and the mobile menu uses a checkbox toggle, so everything works without scripts.
